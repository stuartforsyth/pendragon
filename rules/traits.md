# Personality Traits

Personality Traits (often just **Traits**) quantify and guide a character's
behaviour. Every character has **thirteen opposed pairs**. The two values in a
pair always **sum to 20** (written as `13/7`). As one rises, the other falls by
an equal amount. A character tends to act according to the trait with the
higher value; a value of **16+** may compel behaviour even at inopportune
moments (and grants Glory).

## The 13 trait pairs

| Left (virtue-ish) | Right |
|-------------------|-------|
| Chaste | Lustful |
| Energetic | Lazy |
| Forgiving | Vengeful |
| Generous | Selfish |
| Honest | Deceitful |
| Just | Arbitrary |
| Merciful | Cruel |
| Modest | Proud |
| Prudent | Reckless |
| Spiritual | Worldly |
| Temperate | Indulgent |
| Trusting | Suspicious |
| Valorous | Cowardly |

> Note: in KAP 5e the "pious" trait is named **Spiritual** (Spiritual/Worldly).

## Trait levels

| Level | Value | Meaning |
|-------|-------|---------|
| Unsung | 0–4 | Never known for this trait; the opposite is Famous |
| Normal | 5–15 | Higher of the pair is dominant; closer to 15 = more defining |
| Famous | 16–20 | Strongly defines the character; must be rolled first |
| Exalted | 20 (+x) | Always acts on it; an unmodified Exalted trait never fails |

If both values of a pair are 10, neither is dominant.

## Religious virtues

Certain traits are favoured by a religion; exemplifying them brings benefits
(see [religion.md](religion.md)). A common shorthand:

- **Christian virtues:** Chaste, Forgiving, Merciful, Modest, Spiritual, Temperate
- **Pagan virtues:** Lustful, Energetic, Generous, Honest, Proud, Spiritual
- **Wodinic (Saxon) virtues:** Generous, Indulgent, Proud, Reckless, Valorous, Worldly

## Generating traits (player-knight methods, useful for NPCs)

**Constructed:** All traits start at 10. Raise the religion's favoured traits to
13. Valorous always starts at 15. Then raise one trait to 16 and distribute 6
more points (none above 15). Fill opposites so each pair sums to 20.

**Random:** Roll `2D6+3` for each left-hand trait, except **Valorous = 2D6+8**.
If you roll a religious trait, `+3`; if you roll the opposite of a religious
trait, `−3`. Then set each right-hand value to `20 − left`.

## Using traits for an NPC

A single defining trait line tells you how to play the NPC, e.g.
`Proud 16 / Modest 4` or `Deceitful 14 / Honest 6`. For a quick NPC, roll or
pick **one or two** Famous traits (16+) and leave the rest near 10.
